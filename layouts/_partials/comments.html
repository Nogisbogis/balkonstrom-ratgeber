Kommentare

Die Kommentare werden über giscus aus GitHub Discussions geladen. Erst wenn du auf „Kommentare laden“ klickst, werden Inhalte von giscus.app und github.com nachgeladen. Dabei werden u. a. deine IP-Adresse und Browserdaten an GitHub bzw. giscus übertragen (auch in die USA). Zum Kommentieren brauchst du ein GitHub-Konto. Details in der Datenschutzerklärung.
